Built end-to-end nonlinear PDE simulation software bridging a high-performance C++ nonlinear-analysis core with a flexible Python-based MPI-parallel PDE workflow. Transferred numerical PDE-solving techniques from fluid mechanics to photonic applications for emerging frequency-comb technologies in chip-scale microresonator systems, demonstrating 10x threshold reduction for generating emergent physics in coupled microresonator systems.

Implemented Krylov-subspace iterative methods and preconditioning for efficient optimization, computation and stability analysis of exact invariant solutions.
